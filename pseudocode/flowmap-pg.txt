== Policy
input: noise $z \sim \mathcal{N}(0, I_{L \times V})$, $K$ = `rl.K`, $T$ = `rl.temp`
logits by the rule `rl.option`:
    A: $t_k = t(k/K)$; $x_{k+1} = \hat X_{t_k,t_{k+1}}(x_k)$ for $k < K-1$; $\ell = \ell_{t_{K-1},1}(x_{K-1})$
    B: $t_k = t(k\tau^*/K)$, $\tau^*$ = `rl.tau_star`; $x_{k+1} = \hat X_{t_k,t_{k+1}}(x_k)$ for $k < K$; $\ell = \ell_{t_K,t_K}(x_K)$
$p_{\theta,i}(v \mid z) = \mathrm{softmax}(\ell_i / T)_v$, $y_i \sim \mathrm{Cat}(p_{\theta,i})$ independently
$\log \pi_\theta(y \mid z) = \sum_i \log p_{\theta,i}(y_i \mid z)$   // gradient through all jumps
if `rl.stochastic`: every jump samples (option A), states given, no gradient through them
    for $k = 0, \dots, K-1$: $\hat y_{k,i} \sim \mathrm{Cat}(\mathrm{softmax}(\ell_{t_k,t_{k+1}}(x_k)_i / T))$, $x_{k+1} = \frac{1-t_{k+1}}{1-t_k} x_k + \frac{t_{k+1}-t_k}{1-t_k} \mathrm{onehot}(\hat y_k)$
    $y = \hat y_{K-1}$, $\log \pi_\theta = \sum_{k,i} \log \mathrm{softmax}(\ell_{t_k,t_{k+1}}(x_k)_i / T)(\hat y_{k,i})$

== Update
input: $B$ = `rl.groups` groups of $G$ = `rl.group_size` pairs $(z_g, y_g) \sim \pi_{old}$, rewards $r_g = R(y_g)$
$A_g$ by the rule `rl.advantage`:
    loo: $A_g = r_g - \frac{1}{G-1}\sum_{j \ne g} r_j$
    std: $A_g = (r_g - \bar r)/(s_r + 10^{-6})$, $\bar r$, $s_r$ mean and std of the group
repeat $\mu$ = `rl.mu` times:
    $\rho_{g,i} = p_{\theta,i}(y_{g,i} \mid z_g) / p_{old,i}(y_{g,i} \mid z_g)$
    if $\epsilon_c$ = `rl.clip` is null: $\mathcal{L}_{pg} = -\frac{1}{GL}\sum_{g,i} sg(A_g) \log p_{\theta,i}(y_{g,i} \mid z_g)$
    else: $\mathcal{L}_{pg} = -\frac{1}{GL}\sum_{g,i} \min(\rho_{g,i} A_g, \mathrm{clip}(\rho_{g,i}, 1-\epsilon_c, 1+\epsilon_c) A_g)$
    $\mathcal{L}_{KL} = \frac{1}{GL}\sum_{g,i} KL(p_{\theta,i}(\cdot \mid z_g) \Vert p_{ref,i}(\cdot \mid z_g))$   // $p_{ref}$: frozen pretrained policy from the same $z_g$
    if `rl.stochastic`: $\mathcal{L}_{pg}$ sums over the tokens $\hat y_{g,k,i}$ of all jumps with $A_{g,i}$, divided by $GKL$
    $\mathcal{L}_{rwr} = -\frac{1}{G(K-1)L}\sum_{g,k<K-1,i} sg(A_{g,i}) \log \mathrm{softmax}(\ell_{t_k,1}(x_k)_i / T)(y_{g,i})$   // deterministic states $x_k$, given
    $\mathcal{H} = \frac{1}{GL}\sum_{g,i} H(p_{\theta,i}(\cdot \mid z_g))$, $H(p) = -\sum_v p_v \log p_v$   // if `rl.stochastic`: mean over the logits of all $K$ jumps
    $\theta \leftarrow \mathrm{AdamW}(\nabla_\theta(\mathcal{L}_{pg} + \lambda \mathcal{L}_{rwr} + \beta \mathcal{L}_{KL} - \alpha \mathcal{H}))$, $\lambda$ = `rl.rwr`, $\beta$ = `rl.beta`, $\alpha$ = `rl.entropy`, $\eta$ = `train.lr`

== Conditional version (when the pretrained model has `cond.mode`)
each group shares one question $c_b$ drawn from the training questions; $z_g \in \mathbb{R}^{L_a \times V}$ covers the answer
$\log \pi_\theta(y \mid z, c) = \sum_{i=1}^{L_a} \log p_{\theta,i}(y_i \mid z, c)$, $L_a$ answer length
$r_g$ by the rule `reward`:
    exact: $r_g = \mathbb{1}[y_g = y^*(c_b)]$   // $y^*(c)$: true answer digits
    digits: $r_g = \frac{1}{L_a}\sum_{i=1}^{L_a} \mathbb{1}[y_{g,i} = y^*_i(c_b)]$
    per_digit: $r_{g,i} = \mathbb{1}[y_{g,i} = y^*_i(c_b)]$, one reward per digit; then $A_{g,i}$ = the rule `rl.advantage` applied per digit $i$, e.g. $A_{g,i} = r_{g,i} - \frac{1}{G-1}\sum_{j \ne g} r_{j,i}$, and $A_g \to A_{g,i}$ in $\mathcal{L}_{pg}$
