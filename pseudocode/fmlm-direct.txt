== Time reparameterisation
$1 - P_e(t) = \int \phi(\xi) \Phi(\xi + \frac{t}{1-t})^{V-1} d\xi$   // closed form for one-hot data, Gaussian noise
$\tau(t) = 1 - \frac{V}{V-1} P_e(t)$, tabulated; $t(\tau)$ by interpolation   // only if `model.time_warp`

== Training step
input: batch $x_1^{(1)}, \dots, x_1^{(B)}$ with $B$ = `train.batch_size`, first half for $\mathcal{L}_{diag}$, second half for $\mathcal{L}_{off}$
$x_0 \sim \mathcal{N}(0, I)$
$\tau \sim \mathcal{U}[0,1]$, $t = t(\tau)$, $I_t = (1-t)x_0 + t x_1$
$\mathcal{L}_{diag} = -\frac{1}{L}\sum_l x_1^l \cdot \log \hat\delta_{t,t}(I_t)^l$
$h \sim \mathcal{U}[0,1]$, $\tau_s \sim \mathcal{U}[0, 1-h]$, $\tau_t = \tau_s + h$, $\tau_u = \frac{\tau_s + \tau_t}{2}$
$(s, u, t) = (t(\tau_s), t(\tau_u), t(\tau_t))$, $I_s = (1-s)x_0 + s x_1$
$\hat X_{s,u}(I_s) = \frac{1-u}{1-s} I_s + \frac{u-s}{1-s} \hat\delta_{s,u}(I_s)$
$\gamma = \frac{(1-t)(u-s)}{(1-u)(t-s)}$
$\bar\delta = sg(\gamma \hat\delta_{s,u}(I_s) + (1-\gamma)\hat\delta_{u,t}(\hat X_{s,u}(I_s)))$   // current weights, no EMA
$\mathcal{L}_{off} = -\frac{1}{L}\sum_l \bar\delta^l \cdot \log \hat\delta_{s,t}(I_s)^l$
$\theta \leftarrow \mathrm{AdamW}(\nabla_\theta(\mathcal{L}_{diag} + \mathcal{L}_{off}))$, $\eta$ = `train.lr`
$\bar\theta \leftarrow \lambda \bar\theta + (1-\lambda)\theta$, $\lambda$ = `train.ema`

== Generating samples
input: number of jumps $K$
$x_0 = z \sim \mathcal{N}(0, I)$, $t_k = t(k/K)$
for $k = 0, \dots, K-1$:
    $x_{k+1} = \frac{1-t_{k+1}}{1-t_k} x_k + \frac{t_{k+1}-t_k}{1-t_k}\hat\delta_{t_k,t_{k+1}}(x_k)$
return $y_i = \arg\max_v x_K[i, v]$

== Conditioning on a question (when `cond.mode` is not none)
input: question tokens $c$ = `ab+cd=`, answer one-hot $x_1 \in \{0,1\}^{3 \times V}$
the state, the noise and both losses cover the answer rows only: $I_t = (1-t)x_0 + t x_1$, $x_0 \sim \mathcal{N}(0, I_{3 \times V})$
network input by the rule `cond.mode`:
    state: $h = [\mathrm{onehot}(c) E ; I_t E] + e_{seg}$   // question as clean one-hot rows, same input map $E$
    encoder: $h = [\mathrm{Enc}(c) ; I_t E] + e_{seg}$, $\mathrm{Enc}$ = token embedding + `cond.enc_depth` blocks
$\hat\delta_{s,t}(x \mid c)$ = softmax of the outputs at the answer positions   // $e_{seg}$: learned given / to-generate embedding
if `cond.clamp` (Sudoku, question and answer cells aligned): $G = \{i : c_i \ne 0\}$, the clue cells
    before every network call: $x[i] \leftarrow \mathrm{onehot}(c_i)$ for $i \in G$   // clues never noised
    after every call: $\hat\delta_{s,t}(x \mid c)[i] = \mathrm{onehot}(c_i)$ for $i \in G$   // so only blank cells are generated and carry loss
